# Clario 0.3.0 product readiness

Read FEATURE-AUDIT.md for the current complete feature/status audit and automated evidence. Read CLARIO-START-HERE.md for portable/desktop use and server/README.md for optional service and merchant setup.

This is a reviewable development beta, not a full commercial release. Native capture, OCR, conversion, signed-license verification, signed-update checks, optional share links and payment fulfillment have source implementations and named tests. They do not eliminate the remaining device, configuration, signing, distribution, operations and competitor-parity gaps.

Release blockers: Windows device UAT; successful Windows packaging/startup result; Windows signing; third-party/codec/license distribution review; live seller/merchant/HTTPS service configuration; recovery/refund/device policies; final privacy/terms; the missing capabilities listed in FEATURE-AUDIT.md.

No merge, public product release, merchant setup, deployment, real charge, or outbound customer message has been performed.
