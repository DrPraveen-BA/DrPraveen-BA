# Clario Full Page Capture extension

For testing in Chrome or Edge: open the browser Extensions page, enable Developer mode, select Load unpacked, then select this extension folder. On a normal HTTP(S) page, click the extension and Capture full page; import the downloaded PNG into Clario.

It attaches the browser debugger only to the active tab while explicitly capturing, detaches in finally, and never uploads images. Debugger permission can trigger a visible browser warning and may be blocked by enterprise policy. It cannot capture browser internal pages, protected content, unbounded/infinite scroll, or cross-app scrolling windows. Lazy-loaded content needs to be loaded by scrolling first. Maximum: 8192 pixels per side and 32 megapixels. No Chrome/Edge store listing has been submitted.
